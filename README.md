# Proyecto: Máquina de Snacks

Este repositorio contiene la solución al problema propuesto en la clase del 26/05/2026. El programa simula el funcionamiento de una máquina expendedora de snacks con un saldo inicial de Bs. 5.

## 🚀 Cómo ejecutar el programa
1. Descarga o clona este repositorio.
2. Abre una terminal o consola de comandos en la carpeta del proyecto.
3. Ejecuta el siguiente comando:
   ```bash
   python maquina_snacks.py
